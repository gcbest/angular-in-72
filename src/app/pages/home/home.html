How to use this

Read. Recall. Build.

01

Read for the shape

Do not memorise syntax. Notice the pattern: state in a signal, data in a service, view in a template. Twenty minutes per lesson is enough.

02

Close the tab and say it

Answer the quiz, then explain the idea out loud without looking. If you cannot, reread only that section. Recall beats rereading.

03

Rebuild the search page

On day three, build the product search feature from a blank file. That single exercise covers signals, HTTP, RxJS, routing, forms, and state.
