  1. Open GitHub token settings ↗ and create a token with the gist scope. A fine-grained token with “Gists: read and write” also works.
  2. Paste it above. Leave the gist id blank and the app creates a secret gist for you.

Keep the token private. It is stored only in this browser’s localStorage and sent directly to api.github.com — never committed to the repo. Use a token with only gist access and an expiry date. A secret gist is unlisted, not private; do not store sensitive data in it.
